# Alexandria — Engineering & Product Documentation Package

Thirty documents, in the order the master brief specifies. Each states its
**status**: what is true in the repository today (with file paths), what is
decided but unbuilt (with an ADR or issue-shaped description), and what is
still open research.

This package is documentation, not aspiration: where a document describes
behaviour, it cites the file that implements it. Where it describes intent, it
says so.
