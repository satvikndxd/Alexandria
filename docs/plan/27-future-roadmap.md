# 27 — Future Roadmap

**Status:** ranked backlog · rank = (reader value × identity fit) / ops cost

1. **Reader typography engine** (Phase 3) — the identity feature; everything
   else waits behind it.
2. **Scholar workflow UI** (Phase 4) — the differentiator no competitor has.
3. **Goodreads/StoryGraph import** (Phase 5) — the migration bridge; high
   acquisition value, bounded scope.
4. **LiveKit rooms** (Phase 4) — clubs become places, not threads.
5. **Data export/delete self-service** (Phase 5) — privacy promise completed.
6. **Kindle clipboard parser** (Phase 5) — niche but beloved; zero platform
   risk because it is user-supplied text.
7. **Audiobooks** (Phase 6+) — only public-domain audio (LibriVox), with the
   same rights pipeline; never a hosting business.
8. **University/library integrations** (Phase 6) — Alma/Primo research;
   per-institution config; slow, high-trust value.
9. **E-ink companion** (Phase 7+) — the design system already reads well in
   two colours; a Kobo/Tablet companion is a thin client over the same API.
10. **Multilingual UI + RTL** (Phase 7) — after the reader's typography proves
    itself in one language; Garamond's cousins exist for Greek/Cyrillic.
11. **Federated instances** (research) — AGPL makes this possible; ActivityPub
    for follows/reviews is a thesis, not a plan.

## Permanently out
Ads, paid ranking, engagement dashboards, AI-authored literary content,
credential scraping, read-receipts.
